Task Summary:
- Verify a purely combinational 10-bit binary-to-Gray-code converter.

Behavior To Verify:
- The DUT takes a 10-bit input `bin` and produces a 10-bit output `gray`.
- `gray[9]` must be equal to `bin[9]`.
- For each bit position `i` from 0 to 8, `gray[i]` must equal `bin[i+1] ^ bin[i]`.
- Equivalently, `gray` must equal `bin ^ (bin >> 1)`.
- The output is combinational and must update immediately with changes on `bin`.

Output Semantics:
- There is no sequential state in the intended behavior.
- The testbench should check representative patterns, edge cases, and bit-transition cases across the 10-bit input space.

Verification Objective:
- Generate a self-checking Verilog testbench that verifies the exact Gray-code mapping for directed input values and catches incorrect bit ordering, incorrect XOR logic, or missing combinational updates.
- The testbench should pass the correct RTL and fail incorrect RTL candidates whenever observable behavior allows it.
