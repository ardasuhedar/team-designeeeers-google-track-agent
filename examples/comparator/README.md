# Comparator Toy Example

This folder preserves the original 4-bit comparator prototype that was used to bootstrap the repository.
It is kept as a small reference example for the workflow and evaluator behavior.

Contents:

- `specs/problem.txt`: the original toy natural language problem
- `rtl/`: three candidate comparator implementations
- `generated/tb.v`: a discriminative testbench for the toy example

This example is no longer the main project target.
Active Google Track experiments should use the root-level workflow and an external benchmark repository.
